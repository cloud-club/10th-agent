# 1. 구현하려는 Agent 한 줄 요약

### [AWS 비용 최적화 리뷰 에이전트]

계정의 비용 데이터와 AWS 최적화 권고를 분석하고, 워크로드 상황을 반영해 현재 실행 가능한 비용 절감 조치 목록을 제안하는 에이전트

- 비용 리뷰 시 Cost Explorer와 Compute Optimizer를 각각 확인하고 정리하는 반복 업무를 우선 자동화
- 초기 목표는 리포트 작성까지로 설정하며, 에이전트는 분석과 제안만 수행
- 인스턴스 축소, 유휴 리소스 삭제 등 실제 리소스 변경 여부는 사람이 리포트를 검토한 뒤 결정

# 2. Context 후보 2개

- 비용 및 최적화 권고 데이터
  - Cost Explorer의 비용 추이, 전월 대비 비용 증가 항목, 비용 이상 탐지 결과
  - Compute Optimizer와 Cost Optimization Hub의 라이트사이징 및 유휴 리소스 권고, Savings Plans/RI 커버리지
  - 불필요한 비용이 발생하는 지점과 절감 가능 영역을 판단하기 위한 필수 데이터
  - 비용 수치는 LLM이 직접 계산하거나 추정하지 않고 AWS가 산출한 값을 그대로 사용해, 추정 오류로 인한 리포트 신뢰도 저하 방지

- 워크로드 컨텍스트 및 과거 결정 기록
  - 리소스 태그에 포함된 환경, 서비스, 담당자 정보와 예외 목록
  - 예외 목록에는 월말 배치 작업을 위해 의도적으로 높은 사양을 유지하는 인스턴스, 곧 폐기할 예정인 리소스 등을 포함
  - 이전 리뷰에서의 권고 채택·기각 여부와 기각 사유
  - 권고를 그대로 제시할 때 발생하는 오탐을 줄이고, 이미 파악한 사항이나 변경해서는 안 되는 리소스를 걸러내는 데 활용
  - 앞서 제시된 장애 일지 예시와 유사한 역할을 할 것으로 예상
  - 초기에는 하나의 마크다운 파일로 관리하고 프롬프트에 직접 포함할 예정

# 3. Tool 후보 2개

- 비용 데이터 수집 Tool
  - awslabs의 Billing and Cost Management MCP Server를 사용할 예정
  - Cost Explorer, Budgets, 이상 탐지, Compute Optimizer, Cost Optimization Hub, Savings Plans를 하나의 서버에서 지원하므로 첫 번째 Context에 필요한 데이터를 대부분 확보할 수 있을 것으로 예상
  - 기존 Cost Explorer MCP Server는 deprecated 상태이며 해당 서버로 통합됨
  - 검색 시 기존 서버가 먼저 노출되므로 현재 서버와 구분 필요
  - Cost Explorer API는 요청당 $0.01이 과금되므로 호출 횟수 관리 필요

- 리소스 정보 조회 및 문서 검색 Tool
  - 올해 5월 정식 출시(GA)된 AWS 관리형 원격 서버인 AWS MCP Server를 연동할 예정
  - `call_aws`로 태그와 리소스 구성을 조회하고, `search_documentation`으로 각 권고의 근거 문서를 검색해 첨부
  - 권한은 읽기 전용 역할(read-only role)로 제한
  - MCP 경유 호출에 `aws:ViaAWSMCPService` 등의 조건 키가 자동으로 적용되어 IAM에서 에이전트 호출 경로를 별도로 차단할 수 있다는 설명을 바탕으로, 해당 기능을 활용할 예정
  - 여러 API 결과를 결합할 때는 `run_script`를 활용할 수 있을 것으로 예상하나, 아직 사용 경험이 없어 실제 편의성은 확인 필요

메모
- 에이전트 하나와 Tool 두 개로 구조를 최대한 단순하게 구성
- 처리 순서는 `수집 → 예외 필터링 → 우선순위 설정 → 리포트 작성`으로 고정하며, 동작 방식은 워크플로우에 가까움
- 직접 수행한 리뷰 결과와 비교하고, 권고 채택률을 기준으로 성과를 평가할 예정
- MCP 클라이언트 연동이 용이한 Strands Agents로 구현할 예정
