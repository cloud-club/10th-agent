# 회의록 표준 양식 (회의 後 산출물)

영업 SOP의 "미팅 결과 기록"(논의 내용 → 고객 요구·문제점 → 합의·미합의 → 참석자·역할)을 그대로 양식으로 옮긴 것이다. 에이전트는 비정형 녹취/메모를 이 양식으로 변환하여 저장한다.

## 양식

```markdown
# 회의록 — {고객사} {N}차 회의

- 일시: {YYYY-MM-DD HH:MM}
- 장소/방식: {방문 · 화상 · 전화}
- 회의 목적: {무엇을 얻으려고 누구를 만났는가}

## 1. 참석자
| 구분 | 이름 | 직위/역할 | 비고(결정권 등) |
| --- | --- | --- | --- |
| 고객 | | | |
| 당사 | | | |

## 2. 지난 회의 액션아이템 점검
| 항목 | 담당 | 기한 | 결과(완료 · 진행 중 · 미착수) |
| --- | --- | --- | --- |

## 3. 논의 요지
- {오간 이야기의 요지를 항목으로}

## 4. 고객 요구·문제점
| 구분 | 내용(고객 표현 그대로) | 중요도 | 시급성 |
| --- | --- | --- | --- |
| 문제점 | | | |
| 요구사항 | | | |

## 5. 합의 사항
- {합의한 것}

## 6. 미합의 사항 · 다음 행동
- {아직 정하지 못한 것} → {다음 행동}

## 7. 액션아이템
| 항목 | 담당 | 기한 |
| --- | --- | --- |

## 8. 확보된 표준 질문 항목
- 니즈/정보 확보율: {확보 항목 수}/11 ({%})

| 코드 | 확인 항목 | 상태 | 근거 · 다음 회의 확인 사항 |
| --- | --- | --- | --- |
| Q01 | 고객 문제점 — 현재 상황과 불편 | {이번 확보 · 기존 확보 · 미확보} | {확보: 회의록에서 확인된 내용 한 줄 / 미확보: 다음 회의에서 물어볼 질문} |
```

## 작성 규칙

지시는 "무엇을 하라"의 긍정형으로 적는다. 부정형 지시("~하지 마라")는 모델이 놓치기 쉽다.

1. 고객이 말한 내용은 고객의 표현 그대로 옮긴다.
2. 합의한 것과 정하지 못한 것을 나누어 적고, 미합의 항목마다 다음 행동을 붙인다.
3. 녹취와 고객정보에 있는 내용만 쓴다. 확인되지 않은 항목은 "확인 불가"로 적는다.
4. 담당과 기한이 모두 있는 일만 액션아이템에 올린다. 둘 중 하나라도 비면 미합의 사항에 두고 다음 행동으로 적는다.
5. 고객 측 참석자는 직위와 함께 적어 의사결정 조직 정보를 갱신할 수 있게 한다.
6. "8. 확보된 표준 질문 항목" 표는 Q01~Q11을 모두 한 행씩 적는다. 확인 항목은 표준 질문 리스트의 영역과 질문을 짧게 옮기고, 확보한 항목은 근거를, 미확보 항목은 다음 회의에서 물어볼 질문을 적는다.
7. 표는 한 행을 한 줄에 쓰고, 모든 행의 칸 수를 헤더와 같게 맞춘다. 셀 안에서는 줄을 바꾸지 않고, 세로막대(|) 대신 가운뎃점(·)이나 빗금(/)으로 나눈다. 빈 칸은 "-"로 채운다.
8. 날짜는 "2026-10-08"처럼 연-월-일로 적고, 고객이 한 말은 괄호로 함께 남긴다(예: 2026-10-08 (10월 8일까지)). 날짜를 특정할 수 없으면 고객 표현만 적는다.
