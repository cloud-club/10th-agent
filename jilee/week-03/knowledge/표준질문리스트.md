# 표준 질문 리스트 (회의 前 확인 항목)

영업 SOP의 자격검증 단계(고객 문제점 파악 → 거래 성격 진단 → 해결 기대효과 확인 → 예산·금액 확인)에서 확인해야 하는 항목을 질문 형태로 정리한 것이다. 에이전트는 이 목록과 딜 누적 자료를 대조하여 "아직 확보되지 않은 항목"을 이번 회의의 확인 사항으로 뽑는다.

| 코드 | 영역 | 확인 항목(질문) | 확보 기준 |
| --- | --- | --- | --- |
| Q01 | 고객 문제점 | 고객이 지금 어떤 상황이고 무엇을 불편해하는가 | 고객의 표현 그대로 기록되어 있다 |
| Q02 | 고객 문제점 | 들은 문제가 우리가 대응할 요구사항으로 옮겨져 있는가 | 항목 단위 요구사항이 있고 대응 여부를 판단할 만큼 구체적이다 |
| Q03 | 고객 문제점 | 요구사항마다 중요도와 시급성이 매겨져 있는가 | 필수·선택·가점 구분이 있다 |
| Q04 | 거래 성격 | 도입이 얼마나 급한가 | 긴급도와 그 근거가 되는 고객 일정이 적혀 있다 |
| Q05 | 거래 성격 | 누가 결정하고, 누가 예산을 쥐고, 누가 우리를 도와줄 사람인가 | 결정자·예산 결정권자·내부 지지자가 이름과 직위로 파악되어 있다 |
| Q06 | 거래 성격 | 경쟁사가 들어와 있는가, 기존 공급사가 있는가 | 참여 경쟁사와 기존 공급사, 확인 경로가 남아 있다 |
| Q07 | 기대효과 | 이 문제가 풀리면 무엇이 좋아지는가 | 고객의 말 그대로 기록되어 있다 |
| Q08 | 기대효과 | 금액·시간·건수처럼 나중에 잴 수 있는 값이 있는가 | 값이 적혀 있거나, 없으면 없다고 적혀 있다 |
| Q09 | 예산·금액 | 예산이 확보되어 있는가, 어디서 나오는 돈인가 | 확보·미확보·확인 불가 중 하나와 출처가 적혀 있다 |
| Q10 | 예산·금액 | 예산을 언제 집행할 계획인가 | 집행 예정 시점이 날짜로 있고 회계연도 안팎이 가려져 있다 |
| Q11 | 예산·금액 | 예상 사업금액과 고객이 생각하는 금액은 얼마인가 | 예상 사업금액이 금액으로 있고, 고객 목표금액이 확인된 경우 함께 있다 |

## 확보율 계산

- 니즈/정보 확보율 = (확보 기준을 충족한 항목 수 ÷ 11) × 100
- 확보 판정은 딜 누적 자료(고객정보·지난 회의록)에 해당 내용이 실제로 적혀 있을 때만 한다. 추정으로 채우지 않는다.
