    준비됨

    외부 서비스 연결

    AI 모델과 Google 서비스를 연결해 회의록 작성과 일정 관리를 확장합니다.

    AI 모델 연결저장한 설정은 다음 회의록부터 적용됩니다

    API 키는 서버에만 안전하게 저장하며 화면에 다시 표시하지 않습니다. 기존 키를 유지하려면 입력하지 않아도 됩니다.

    기본 모델

    예비 모델 기본 모델을 사용할 수 없을 때 자동으로 사용합니다

    어떤 모델이 적합한가요?

    ① 도구 호출을 지원한다(위의 연결 테스트가 확인) ② 한 요청에 입력 3만 토큰 이상을 받는다(4차 회의의 가장 큰 요청이 약 3만 토큰) ③ 회의 한 건에 4~8회 호출, 입력 합계 3만~10만 토큰을 감당하는 한도 ④ 한국어 회의록을 양식대로 쓴다(저장 전 규칙 검사 통과율로 본다) ⑤ 입력을 학습에 쓰지 않는 조건(실데이터를 넣기 전에 확인)

    Google 서비스 연결Calendar · Docs

    Google 계정으로 연결

    구글 클라우드 콘솔에서 Calendar API와 Drive API를 켜고, 웹 애플리케이션 OAuth 클라이언트를 만든 뒤 승인된 리디렉션 URI에 를 넣습니다.

    일정만 가져오기

    Google Calendar의 비공개 iCal 주소를 입력하면 일정을 읽기 전용으로 가져옵니다.

    이 앱의 일정을 Google Calendar에서 보기

    구글 캘린더 › 다른 캘린더 › "URL로 추가"에 아래 주소를 넣습니다. 구글 서버가 이 주소에 닿아야 하므로 로컬에서는 되지 않고, 서버에 올린 뒤에 쓸 수 있습니다. 구글은 구독한 주소를 몇 시간에 한 번만 다시 읽습니다.
    
        
    
        
    
          
    개발자 API다른 사내 시스템과 연결할 때 사용합니다
    
          
    
            
    GET /api/meetings모든 프로젝트의 회의와 문(게이트) 상태, 남은 할 일
    
            
    GET /api/calendar회의·진행 예정·계약 예상일·구글 일정
    
            
    GET /calendar.ics?token=캘린더 구독용 iCal
    
            
    GET /api/sheet?customer_id=&project_id=결과지: 항목별 값·근거·상태·이력, 담당자와 연락처, 거래 조건, 완결성
    
            
    GET /api/graph?customer_id=&project_id=노드와 선(일의 흐름 · 관계)
    
            
    POST /api/run{"customer_id","project_id","meeting_no","transcript"} 녹취를 넣고 에이전트 실행(진행 단계가 SSE로 내려옴)
    
            
    POST /api/minutes/confirm회의록 확정 → 결과지에 AI 초안으로 반영
    
            
    POST /api/minutes/edit{"markdown"} 회의록 초안을 사람이 고쳐 저장
    
            
    POST /api/sheet/confirm{"kind","target"} 결과지 값 확인
    
            
    POST /api/file?…&name=첨부파일 올리기(본문이 파일). GET /api/files로 목록, GET /api/file로 내려받기
    
            
    POST /api/chat{"messages","customer_id","project_id"} 읽기 전용 질의
