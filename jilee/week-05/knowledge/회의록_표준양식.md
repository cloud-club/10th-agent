# 회의록 표준 양식 (결과지의 근거 문서)

영업 SOP의 "미팅 결과 기록"(논의 내용 → 고객 요구·문제점 → 합의·미합의 → 참석자·역할)을 그대로 양식으로 옮긴 것이다. 회의록은 리드 결과지의 접촉 이력 한 줄에 붙는 근거 문서다. 무엇이 확보되었는지는 회의록이 아니라 결과지에 적는다.

## 양식

```markdown
# 회의록 — {고객사} {N}차 회의

- 일시: {YYYY-MM-DD HH:MM}
- 장소/방식: {방문 · 화상 · 전화}
- 회의 목적: {무엇을 얻으려고 누구를 만났는가}
- 핵심 요약: {회의에 없던 사람이 읽어도 맥락이 잡히게 줄글 서너 문장으로. 왜 만났나 → 무엇이 정해졌나 → 지난번과 무엇이 달라졌나 → 무엇이 남았나}

## 1. 참석자
| 구분 | 이름 | 직위/역할 | 비고(결정권 등) |
| --- | --- | --- | --- |
| 고객 | | | |
| 당사 | | | |

## 2. 지난 회의 액션아이템 점검
| 항목 | 담당 | 기한 | 결과(완료 · 진행 중 · 미착수) |
| --- | --- | --- | --- |

## 3. 논의 요지
### {주제} — {이 주제에서 난 결론 한 줄}
{배경과 경위를 줄글 한두 문장으로. 머리말 없이 바로 문장으로 쓰고, 발화 번호(#12)는 적지 않는다. 예: 공장장이 감사 전에 한 라인만 먼저 하자던 2차 회의의 입장을 다시 꺼냈으나, 두 라인이 같은 하우징 계열이라 셋업을 나누면 비용이 는다는 설명을 듣고 동시 진행에 동의함.}
- **[중요]** {결론을 가른 핵심 논의}
  - {그 근거가 된 숫자·조건·누가 한 말인지}
- {그 밖에 오간 이야기}

### {다음 주제} — {결론 한 줄}
- …

## 4. 고객 요구·문제점
| 구분 | 내용(문제·요구가 무엇이고 이번 회의에서 어떻게 정해졌는지) | 중요도 | 시급성 |
| --- | --- | --- | --- |
| 문제점 | | | |
| 요구사항 | | | |

## 5. 합의 사항
- **{주제}**: {합의한 것}

## 6. 미합의 사항 · 다음 행동
- **{주제}**: {아직 정하지 못한 것} → {다음 행동}

## 7. 액션아이템
| 항목 | 담당 | 기한 |
| --- | --- | --- |
```

## 작성 규칙

지시는 "무엇을 하라"의 긍정형으로 적는다. 부정형 지시("~하지 마라")는 모델이 놓치기 쉽다.

글투: 사람이 쓴 사내 회의록처럼 개조식으로 끊어 쓴다(~함, ~하기로 함, ~예정, ~필요). 누가 무엇을 왜 그렇게 정했는지를 적고, 주어를 감춘 말("논의됨", "공유됨", "진행됨")로 뭉개지 않는다. 핵심 요약과 주제 아래 첫 줄만 줄글로 쓴다.

내부 회의(고객이 참석하지 않은 회의)는 "4. 고객 요구·문제점"의 제목을 "4. 쟁점·검토 사항"으로 쓰고, 구분 칸에 쟁점 · 검토 · 결정 필요를 적는다.

0. "3. 논의 요지"는 오간 말을 순서대로 늘어놓는 곳이 아니다. 주제 3~6개로 묶고(예: 성능·검증 / 범위·일정 / 금액·결제 / 계약 조건 / 후속 지원), 주제마다 제목에 결론을 적는다. 결론을 가른 논의에는 **[중요]**를, 앞서 한 말이 뒤집힌 것에는 **[번복]**을 붙인다. 숫자와 조건, 누가 한 말인지는 한 칸 들여 쓴 아래 줄에 적는다. 한 주제에 다섯 줄을 넘기지 않는다.
1. 회의록은 결과 중심으로 쓴다. 문제점·요구사항은 발화를 옮겨 적지 않고, 무엇이 문제이고 무엇을 원하는지와 그 결과(수용 · 검토 · 보류)를 정리해 적는다. 숫자·조건·고유명사는 녹취 그대로 둔다. 발화 원문은 뜻이 갈릴 수 있는 대목에만 짧게 따옴표로 남긴다. 중요도·시급성은 상 · 중 · 하로 적는다. "4. 고객 요구·문제점"의 내용 칸은 "{문제 또는 요구} → {이번 회의의 결정: 수용 · 조건부 수용 · 검토 · 보류와 그 내용}" 꼴로 적고, 따옴표로 발화를 옮기지 않는다.
2. 합의한 것과 정하지 못한 것을 나누어 적고, 미합의 항목마다 다음 행동을 붙인다.
3. 녹취와 고객정보에 있는 내용만 쓴다. 확인되지 않은 항목은 "확인 불가"로 적는다.
4. 담당과 기한이 모두 있는 일만 액션아이템에 올린다. 둘 중 하나라도 비면 미합의 사항에 두고 다음 행동으로 적는다. "4. 고객 요구·문제점"에는 이번 회의에서 새로 나오거나 달라진 것만 적고, 다섯 줄 안팎으로 줄인다. "5. 합의 사항"에는 정해진 것만 적고, 누가 언제까지 무엇을 할지는 액션아이템에만 적는다.
5. 고객 측 참석자는 직위와 함께 적는다.
6. 표는 한 행을 한 줄에 쓰고, 모든 행의 칸 수를 헤더와 같게 맞춘다. 셀 안에서는 줄을 바꾸지 않고, 세로막대(|) 대신 가운뎃점(·)이나 빗금(/)으로 나눈다. 빈 칸은 "-"로 채운다.
7. 날짜는 "2026-10-08"처럼 연-월-일로 적고, 고객이 한 말은 괄호로 함께 남긴다(예: 2026-10-08 (10월 8일까지)). 날짜를 특정할 수 없으면 고객 표현만 적는다.
