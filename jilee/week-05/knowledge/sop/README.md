# knowledge/sop — 영업 SOP 정본 배치 위치

SOP 서브에이전트(`agent/sop_agent.py`)가 검색하는 사내 영업 SOP 문서를 두는 곳이다. 사내 문서이므로 저장소에는 올리지 않고, 실행 환경에 직접 복사한다.

- 배치 대상: 영업 SOP 정본 마크다운 10편(확정판정·프로세스지도·액티비티지도·태스크지도·서브태스크 2편·실행가이드·흐름동학·작성방법론·RACI지도)
- 형식: `.md`. 제목(`#`·`##`·`###`) 또는 표 행 단위로 분할해 검색하므로 형식 변환 없이 그대로 둔다
- 문서가 없으면 `consult_sop` 도구는 "관련 문단을 찾지 못했습니다"를 돌려주고, 회의록 작성 자체는 영향받지 않는다
