## 1. Agent
### 1.1 길잡비스 Gil-jabvis 

길잡비스는 놀러 간 곳에서 채팅으로 물어보면 현재 위치 기반 장소를 함께 추천하고, 미리 짠 플랜에 따라 다음 코스까지 제안해 주는 에이전트이다. 

#### 기존 문제 
- 음식점, 카페 등 장소를 찾으려면 지도 앱, 블로그 앱을 오가야 한다. 
- 게다가 미리 짜 둔 일정은 별개의 메모로 존재하여 현 상황과 연결이 어렵다. 

#### 시나리오 
1. 홍대에 도착해서 채팅에 "이 근처 망고 맛있는 카페 알려줘"라고 입력한다. 
2. 에이전트가 내 위치 주변을 검색하여 후보와 추천 이유를 함께 답변하며 지도에 마커로 표시한다. 
3. 일정 전에 "라멘 -> 디저트 카페"와 같은 플랜을 등록해 두면, 라멘집에 있을 때 "다음 코스는 여기 어때요"? 제안한다. 

## 2. Tool 
1. 장소 검색 
    - 위치 주변에서 키워드로 장소 검색  
    - Input: 검색어, 위도/경도, 반경, 카테고리 
    - Data Source: 카카오 로컬 API 
2. 지도 표시 
    - 추천 장소를 지도에 마커로 표시 
    - Input: 장소 목록(이름, 좌표)
    - Data Source: 카카오맵 
3. 여행 플랜 등록, 조회 
    - 여행 플랜 등록, 조회 
    - Input: 날짜, 순서, 장소, 메모 
    - Data Source: 자체 DB 
4. 이동시간 조회 
    - 두 장소 간 이동 시간 
    - Input: 출발지, 도착지, 이동 수단 
    - Data Source: 길찾기 API 
5. 날씨 조회 
    - 현재/예정 날씨 
    - Input: 좌표, 시간 
    - Data Source: 날씨 API 
6. 후기, 메뉴 검색 
    - 메뉴, 후기 보강 
    - Input: 장소명, 키워드 
    - Data Source: 웹 검색

## 4. 예상 문제 
1. 환각: 없는 가게나 메뉴  
    - 추천은 반드시 도구 결과에서만 하도록 지침에 명시하고 결과에 없는 정보는 "확인되지 않았어요" 답변 
2. 메뉴 정보 부족
    - 장소 API는 메뉴까지 주지 않기에 후기 검색으로 보강하거나 범위 축소 우려 
3. 평가 
    - 추천이 좋았는지 어떻게 판단할지 기준은 아직 정하지 못함
